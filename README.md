# india-textiles-export-market-entry
Data-driven market entry analysis for Indian cotton home textile exports.
# India Textile Export: Market Entry Analysis

## Business question
An Indian exporter of cotton home textiles (HS 6302) wants to enter one new overseas market. Which of five candidate countries (USA, UK, Germany, UAE, Australia) offers the best opportunity, and which entry mode (exporting, licensing, joint venture, or FDI) suits it best?

## Approach
Score each country on market size, growth, trade barriers, competition, risk, and logistics using public data, then recommend an entry mode for the top scorers.

## Tools
Excel, Python (pandas), Power BI

## Data sources
UN Comtrade / ITC Trade Map, World Bank, WITS, UNCTAD
